# راز — مساحة تفكيرك

تطبيق محادثة عربي بواجهة RTL، يعمل بخلفية Node.js وExpress ويتصل بنماذج Mistral المتاحة لمفتاحك. يكتشف النماذج تلقائياً، ويجرّب النماذج البديلة عند تعذّر أحدها. تُحفظ المحادثات محلياً في متصفحك.

## ال��شغيل محلياً

1. ثبّت Node.js 20 أو أحدث.
2. انسخ ملف الإعدادات ثم أضف مفتاح Mistral الخاص بك:

   ```bash
   cp .env.example .env
   ```

   عيّن `MISTRAL_API_KEY` في `.env`، ويمكنك تغيير `PORT` (الافتراضي 3000).
3. ثبّت الاعتماديات وشغّل وضع التطوير:

   ```bash
   npm install
   npm run dev
   ```
4. افتح [http://localhost:3000](http://localhost:3000).

لإنشاء نسخة الإنتاج وتشغيلها:

```bash
npm run build
npm start
```

## النشر على Render

1. ادفع هذا المستودع إلى GitHub وأنشئ خدمة **Web Service** جديدة في [Render](https://render.com/).
2. اربط مستودع GitHub وحدد الفرع `main`.
3. استخدم الإعدادات التالية:
   - **Runtime:** Node
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm start`
4. في **Environment**, أضف `MISTRAL_API_KEY` بقيمة مفتاحك. أضف `PORT` فقط عند الحاجة؛ Render يمرر المنفذ المناسب تلقائياً.
5. انشر الخدمة وافتح رابط Render. لا تضع مفتاح API في ملفات الواجهة أو في المستودع.

## نقاط النهاية

- `GET /api/models` — النموذج الافتراضي والنماذج المتاحة.
- `POST /api/chat` — يستقبل `{ "message": "...", "history": [] }` ويرسل الأحداث النصية عبر SSE. يتضمن حدث `model` اسم النموذج وحدث `token` أجزاء الرد.

النماذج المتاحة تُخزّن مؤقتاً لمدة ساعة، كما يُتذكر آخر نموذج ناجح للساعة التالية.
